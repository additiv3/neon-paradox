# NEON PARADOX

Zeitschleifen-Arena-Shooter fürs Handy und den PC. **Spielen:** https://additiv3.github.io/neon-paradox/

Jede Runde wird aufgezeichnet – in der nächsten kämpft deine Vergangenheit als Echo an deiner Seite.

Auf dem iPhone in Safari öffnen, dann *Teilen* → *Zum Home-Bildschirm*. Das Spiel läuft komplett im
Browser, funktioniert nach dem ersten Laden auch ohne Internet und speichert den Spielstand nur auf
dem eigenen Gerät. Am besten im Querformat und mit Ton spielen.

Dieses Repository enthält nur das fertige Spiel. Es wird automatisch veröffentlicht.
